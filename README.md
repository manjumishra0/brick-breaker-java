# 🧱 Brick Breaker Game (Java)

A classic Breakout-style game built using **Java Swing** in IntelliJ IDEA.
Move the paddle, bounce the ball and break all the bricks to win!

## 🎮 Features
- 21 bricks (3 rows x 7 columns)
- Score system: +5 points for every brick (maximum score: 105)
- Paddle movement with arrow keys
- Ball bounces off walls, paddle and bricks
- "You Won" and "Game Over" screens with restart option

## ⌨️ Controls
| Key | Action |
|-----|--------|
| ← / → | Move paddle (also starts the game) |
| Enter | Restart after Game Over / Win |

## 🛠️ Tech Used
- Java
- Java Swing & AWT
- OOP concepts (classes, objects, encapsulation)

## 📁 Project Structure
- `Main.java` - creates the game window
- `GamePlay.java` - game logic, ball and paddle movement, collisions, drawing
- `MapGenerator.java` - creates and draws the bricks

## ▶️ How to Run
1. Download the repository (Code → Download ZIP) and unzip it.
2. Open the folder in IntelliJ IDEA using File → Open.
3. Open `src/brickBraker/Main.java` and click the Run button.
